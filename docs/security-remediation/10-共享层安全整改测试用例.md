# 共享层安全整改测试用例

> 文档口径（v2.0.3，2026-11-26）：当前发布版本 **v2.0.3**；`pytest` **499 passed / 1 skipped**，Node **43 passed**；用户启动方式统一为安装 `setup.exe`。本文历史章节中的旧版本/测试数字仅代表当时基线，最新口径以根目录 `README.md` 与 `CHANGELOG.md` 为准。


## 1. 测试范围

覆盖默认管理员/Demo、登录限流、PBKDF2 写锁、配置加载、生产安全、健康检查、CSRF/安全头、审计/日志、共享路由注册及与 A/B/C/D 的集成。

## 2. 测试环境及依赖

- 代码基线：共享层安全基线分支（从 `integration/v1.2` 创建，经 SFCR 应用）。
- pytest 8.3.4、FastAPI TestClient、临时 SQLite、线程测试。
- 运行目录：`SR`。
- 命令示例：

```bash
python -m pytest tests/test_api.py tests/test_account_api.py tests/test_concurrency.py -q
```

- 配置测试通过 `monkeypatch.setenv`/临时 `.env`；不得修改系统环境。
- 日志测试使用 tmp_path/handler，不写正式日志。

## 3. 测试数据准备

- 临时 DB；生产/测试 Settings。
- 账号：sysadmin、room_admin、student、teacher，以及待创建临时账号。
- Demo 模式/非 Demo/Production 三套 Settings。
- ACS token 测试值使用临时常量。
- 日志/审计使用临时 DB，不写真实身份信息。

## 5. 详细测试样例

### SH-SEC-001 密码哈希/令牌原语单元

- **测试类型：** 单元
- **对应审计问题：** H-01 / M-01
- **测试目的：** 验证 PBKDF2 盐/迭代、verify、token 随机性、常量时间比较。
- **前置条件：** `security.py`。
- **测试步骤：**
  1. hash 同一密码两次，比较编码。
  2. verify 正确/错误/损坏编码。
  3. 生成 token/csrf，检查长度/随机性。
- **输入数据：** `Passw0rd!23`、错误密码、损坏 hash。
- **预期结果：** 盐不同、hash 不同；正确 verify true；错误/损坏 false；token 长度足够且不重复；常量时间函数空值 false。
- **测试方式：** pytest 单元。
- **优先级：** P1

### SH-SEC-002 用户名规范化/限流 key 单元

- **测试类型：** 单元
- **对应审计问题：** M-01
- **测试目的：** 验证 strip/casefold 后相同账号共用 key。
- **前置条件：** 新增 normalization 函数/limiter key 函数。
- **测试步骤：**
  1. 对 `S1`、` S1`、`S1 `、`\tS1`、`s1` 计算 key。
  2. 对 Unicode 空白/大小写变体。
- **输入数据：** 变体列表。
- **预期结果：** 全部相同 key；不同账号不同 key；空/超长输入拒绝或规范。
- **测试方式：** pytest 单元。
- **优先级：** P0

### SH-SEC-003 限流阈值/清理单元

- **测试类型：** 单元
- **对应审计问题：** M-01
- **测试目的：** 验证 5 次失败锁定、窗口过期、清理/容量。
- **前置条件：** `LoginRateLimiter`。
- **测试步骤：**
  1. 同 key 5 次失败 → check 抛 RateLimited。
  2. 时间推进超过 lock → 可重试。
  3. 创建大量 key，触发清理/上限。
- **输入数据：** now/window/lock；大量 unique keys。
- **预期结果：** 阈值正确；过期释放；内存 key 数量受限；不无限增长。
- **测试方式：** pytest 单元。
- **优先级：** P0

### SH-SEC-004 环境配置规范化单元

- **测试类型：** 单元
- **对应审计问题：** M-02
- **测试目的：** 验证 env 去空格/大小写、未知值失败、生产校验。

- **测试步骤：**
  1. `SEAT_ENV=" production "`。

  3. `SEAT_ENV=unknown`。
  4. `.env` 加载策略（按最终选择）。

- **测试方式：** pytest 单元/monkeypatch。
