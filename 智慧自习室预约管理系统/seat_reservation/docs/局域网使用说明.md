# 局域网访问说明

适用于「一台主机跑服务，同一 Wi-Fi 或交换机下的其他设备用浏览器访问」的场景，例如自习室值班电脑开服务，学生用手机、平板或教室电脑访问。

## 1. 前置条件

- 主机已安装 Python 3.11 及以上，并装好 `requirements.txt` 依赖。
- 主机与访问设备在**同一局域网**（同一路由器、同一交换机，或同一校园网段）。
- 主机防火墙允许 TCP 8010 入站（见第 4 节）。
- 主机保持开机，Python 服务保持运行；主机关机或服务停止后网页无法访问，但数据仍在主机磁盘上。

## 2. 启动服务

在 `智慧自习室预约管理系统/seat_reservation` 目录执行：

```powershell
.\.venv\Scripts\python.exe run.py --db var/delivery.db serve --lan --port 8010
```

- `--lan` 等价于监听 `0.0.0.0`，即所有网卡；不加 `--lan` 时只监听 `127.0.0.1`，其他设备访问不到。
- 启动后终端会打印访问地址，例如：

```text
服务启动后可访问以下地址（请等待 Uvicorn 启动成功）：
本机：http://127.0.0.1:8010/
局域网候选：http://192.168.1.23:8010/
其他设备请选择主机 Wi-Fi/以太网 IPv4 地址；可运行 ipconfig 查看。
主机与客户端须在同一局域网，并允许该端口通过专用网络防火墙。
0.0.0.0 是监听地址，不能作为其他设备的访问地址。
```

`0.0.0.0` 只是监听地址，**不能**拿它去访问；其他设备要用具体的 IPv4 地址。

## 3. 确认主机 IPv4

Windows 下执行：

```powershell
ipconfig | findstr /i "IPv4"
```

- 有线网络看「以太网适配器」，无线看「无线局域网适配器 WLAN」。
- 不要选 `127.0.0.1`、`169.254.x.x`（未获取到地址时的自动地址），以及 VPN、Hyper-V、VMware 等虚拟网卡。
- 候选地址可能不止一条，用另一台设备逐个试即可。

确认后，在手机或电脑浏览器打开：

```text
http://<主机IPv4>:8010/
```

## 4. 放行 Windows 防火墙

首次启动时 Windows 可能弹出「是否允许访问网络」，勾选**专用网络**并允许。

如果没有弹窗或误点了拒绝，用管理员 PowerShell 添加规则：

```powershell
New-NetFirewallRule -DisplayName "自习室预约 8010" -Direction Inbound -Protocol TCP -LocalPort 8010 -Action Allow -Profile Private
```

只对专用网络开放，不要对「公用网络」开放。需要撤销时：

```powershell
Remove-NetFirewallRule -DisplayName "自习室预约 8010"
```

## 5. 常见问题

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 主机能打开，其他设备打不开 | 启动时没加 `--lan`，或防火墙拦截 | 用 `--lan` 重启；按第 4 节放行 8010 |
| 浏览器提示「无法访问此网站」 | IPv4 选错（选了 VPN/虚拟网卡），或不在同一网段 | 对比两台设备 IP 的前三段是否一致 |
| 昨天能用今天不能 | 主机通过 DHCP 换了 IP | 在路由器上给主机绑定静态 IP，或重新执行 `ipconfig` |
| 能 ping 通但网页打不开 | 端口被占用或服务未启动 | 运行 `netstat -ano` 查看 8010 是否被其他进程占用；确认终端没有报错 |
| 同一 Wi-Fi 下互相访问不了 | 路由器开了 AP 隔离/客户端隔离，或校园网限制 | 换到同一交换机，或请网络管理员放行 |
| 直接访问 `0.0.0.0:8010` 打不开 | `0.0.0.0` 是监听地址，不是目标地址 | 改用主机具体的 IPv4 |

## 6. 外网访问

临时演示可以另开一个终端：

```powershell
ngrok http 8010
```

把 ngrok 给出的 HTTPS 地址发给对方即可。需要注意：

- 免费版域名每次重启都会变化；
- ngrok 只做转发，不保存业务数据，主机服务必须一直运行；
- 长期或正式使用不要依赖 ngrok，应使用 Nginx 等反向代理 + 域名 + HTTPS。

## 7. 安全提醒

- `--lan` 会把服务暴露给同网段的所有设备，只在学校、自习室等可信网络使用。
- 暴露到公网必须走 HTTPS；生产环境设置 `SEAT_ENV=production`、`SEAT_COOKIE_SECURE=true`，否则启动会失败。
- 经过反向代理时设置 `SEAT_TRUST_PROXY=true` 并透传 `X-Forwarded-For`，否则审计日志里的来源 IP 全是 `127.0.0.1`。
- 初始账号与密码规则见仓库根目录 `README.md` 第 4 节；非系统管理员首次登录必须改密。

生产部署（Nginx、systemd、HTTPS、备份）见同目录的 [`技术文档.md`](技术文档.md) 第一部分。
