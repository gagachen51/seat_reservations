# 环境清单

> 对应项目：`seat_reservation/`（智慧自习室预约管理系统 v2.0.0）
> 实际测量时间：2026-10-30
> 本文所有数值均为本机实测，非估算。

## 1. 操作系统

| 项目 | 实际值 |
|---|---|
| 操作系统 | Windows 11（`10.0.22631`） |
| 架构 | AMD64（x64） |
| 命令行环境 | Git Bash / PowerShell / cmd 均可 |
| 字符编码 | UTF-8 |
| 时区 | 本地时区。程序统一使用 naive `datetime`，不做时区换算 |

## 2. 运行时

| 项目 | 实际值 | 说明 |
|---|---|---|
| Python | **3.13.14** | `pyproject.toml` 声明 `requires-python = ">=3.11"`，3.11 / 3.12 / 3.13 均可 |

| 内存占用 | 约 60MB（服务 + 页面） | 桌面窗口模式含 WebView2 子进程约 136MB |

## 4. 命令清单

以下命令在 `seat_reservation/` 目录执行。

### 4.1 安装依赖

```bat
python -m pip install -r requirements.txt
```

### 4.2 启动（三种方式）

```bat
:: 方式一：网页版，浏览器访问 http://127.0.0.1:8010
python run.py --db var/web.db init-db --demo
python run.py --db var/web.db serve --port 8010 --demo

:: 方式二：桌面窗口（无浏览器地址栏，自绘标题栏）
python desktop_launcher.py

:: 方式三：直接用交付的安装包
dist\setup.exe
```

### 4.3 测试

```bat
python -m pytest -q
```

预期结果：**115 passed, 1 skipped**（未安装 playwright 的口径；装上后为 115 通过 / 3 跳过）。端到端浏览器测试需 `SEAT_E2E=1` 才会执行。

### 4.4 命令行工具

```bat
python run.py --help
```

| 子命令 | 作用 |
|---|---|
| `init-db` | 执行数据库迁移 |
| `seed` | 写入演示数据（会清空业务表） |
| `serve` | 启动 HTTP 服务 |
| `sweep` | 执行一次超时扫描（判违约、释放座位） |
| `user` | 账号管理（新建、改密码、改角色） |
| `params` | 查看与修改业务参数 |
| `export` | 导出 CSV（reservations / violations / audit） |
| `prune` | 清理超期终态预约 |
| `doctor` | 环境与数据自检 |

### 4.5 重新打包

```bat
:: 1. 主程序（onedir）
python -m PyInstaller --noconfirm --noconsole --name "自习室预约" ^
  --icon "assets/app.ico" --paths src --collect-submodules seat_reservation ^
  --collect-all webview --hidden-import clr --hidden-import webview.platforms.edgechromium ^
  --add-data "src/seat_reservation/web;seat_reservation/web" ^
  --hidden-import uvicorn.logging --hidden-import uvicorn.loops.auto ^
  --hidden-import uvicorn.loops.asyncio --hidden-import uvicorn.protocols.http.auto ^
  --hidden-import uvicorn.protocols.http.h11_impl ^
  --hidden-import uvicorn.lifespan.on desktop_launcher.py

:: 2. 安装程序（onefile，把上一步产物作为资源打包）
python -m PyInstaller --noconfirm --noconsole --onefile --name "setup" ^
  --icon "assets/app.ico" --add-data "dist/自习室预约;app" ^
  --collect-all webview --hidden-import webview.platforms.edgechromium ^
  --hidden-import clr installer.py
```

产物：`dist/setup.exe`（32MB 单文件）、`dist/自习室预约/`（38MB 绿色版）。

## 5. 存储位置

| 场景 | 数据库位置 |
|---|---|
| 绿色版运行 | `dist/自习室预约/data/seat_reservation.db` |
| 安装版运行 | 安装目录下 `data/seat_reservation.db` |
| 开发调试 | 项目下 `var/`（自动创建） |

数据**跟随程序所在目录**：装到 D 盘，数据库就在 D 盘，不写 C 盘用户目录。
唯一例外是装进 `Program Files` 这类不可写位置，此时退回 `%LOCALAPPDATA%\SeatReservation`。

日志在同级 `logs/launcher.log`。

## 6. 分发形态

| 文件 | 体积 | 用途 |
|---|---|---|
| `dist/setup.exe` | 32MB | 安装包，双击安装。自选目录、建快捷方式、可卸载 |
| `dist/自习室预约/` | 38MB | 绿色版，解压即用，不写注册表 |

两者都**自带 Python 运行时**，目标机器无需安装 Python、无需装数据库、无需配置。

## 7. 已知限制

- **仅 Windows**。PyInstaller 不支持跨平台交叉编译，Linux / macOS 版本需在对应系统上重新打包。
- **单机 SQLite**，不支持多节点同时写入。需要横向扩展时应替换为 PostgreSQL 仓储实现。
- **未做并发压测**，200 并发的性能指标尚无实测数据。
- **安装包未数字签名**，他人首次运行时 Windows SmartScreen 可能提示"未知发布者"。这是缺少代码签名证书所致，不是程序缺陷。
- 浏览器兼容性仅验证 Chromium 内核（Edge / Chrome），Safari 与 Firefox 未做回归。
- 时间使用本地 naive `datetime`，不含时区换算。
- 未接入真实统一身份认证、门禁与消息推送，账号与凭证签发为教学模拟。
