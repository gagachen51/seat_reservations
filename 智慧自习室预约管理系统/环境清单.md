# 智慧自习室预约管理系统 · 环境清单

本文列出运行、开发与验收所需的软硬件环境。系统为单体 Web 服务，只需 Python 运行时与一个可写的本地目录，不依赖独立数据库服务、消息队列或前端构建工具。

## 1. 运行环境

| 项 | 要求 | 本次验证环境 |
|---|---|---|
| 操作系统 | Windows 10/11、Windows Server 2019+、主流 Linux 发行版 | Windows 11 |
| Python | 3.11 及以上 | 3.13.12 |
| SQLite | Python 标准库自带（需支持 WAL，3.7 以上） | 3.50.4 |
| 浏览器 | Chromium 内核（Edge / Chrome）；Safari、Firefox 未做完整回归 | Edge |
| 内存 | 512 MB 起，建议 1 GB | — |
| 磁盘 | 源码与测试约 3 MB，虚拟环境约 37 MB；数据库按每万条预约约 20 MB 估算 | — |
| 网络 | 本机访问即可；局域网访问需放行端口；外网访问需反向代理或 ngrok | — |

数据库文件必须放在**本地磁盘**。SQLite 的 WAL 依赖文件锁，放在网络共享盘、云同步目录或被安全软件实时扫描时，并发写入可能报 `attempt to write a readonly database`。

## 2. 依赖清单

`requirements.txt` 锁定以下版本：

| 依赖 | 版本 | 用途 |
|---|---|---|
| `fastapi` | 0.115.6 | HTTP 路由、请求校验、依赖注入 |
| `uvicorn` | 0.34.0 | ASGI 服务器 |
| `pydantic` | 2.10.4 | 请求/响应模型与配置校验 |
| `segno` | 1.6.6 | 生成座位桌贴二维码（纯 Python，无编译依赖） |
| `pytest` | 8.3.4 | 后端自动化测试 |
| `httpx` | 0.28.1 | FastAPI `TestClient` 的传输层 |

前端为原生 HTML/CSS/JavaScript，无 npm、无打包步骤；`node` 仅用于运行前端单元测试（Node 18 及以上）。

## 4. 端口

| 端口 | 用途 | 说明 |
|---|---|---|
| 8010 | 应用默认端口 | 可用 `--port` 或 `SEAT_PORT` 修改 |
| 4040 | ngrok 本地控制台 | 仅在运行 ngrok 时占用 |

## 5. 环境变量

优先级：进程环境变量 > `.env` 文件 > 代码默认值。

| 变量 | 默认值 | 说明 |
|---|---|---|
| `SEAT_ENV` | `development` | 仅接受 `development` / `dev` / `test` / `production` / `prod`，非法值拒绝启动 |
| `SEAT_DB_PATH` | `var/delivery.db` | 数据库路径；显式 `--db` 优先 |
| `SEAT_HOST` | `127.0.0.1` | 监听地址；`--lan` 等价于 `0.0.0.0` |
| `SEAT_PORT` | `8010` | 监听端口 |
| `SEAT_LOG_LEVEL` | `INFO` | 日志级别 |
| `SEAT_LOG_JSON` | `false` | 是否输出 JSON 结构化日志 |
| `SEAT_SESSION_IDLE_MINUTES` | `30` | 会话空闲超时 |
| `SEAT_SESSION_ABSOLUTE_HOURS` | `8` | 会话绝对超时 |
| `SEAT_COOKIE_SECURE` | `false` | 生产环境必须为 `true`，否则拒绝启动 |
| `SEAT_TRUST_PROXY` | `false` | 仅在可信反向代理之后开启，开启后读取 `X-Forwarded-For` |
| `SEAT_DEMO_MODE` | `false` | 演示模式，仅 `development` / `test` 可用 |
| `SEAT_SCHEDULER_ENABLED` | `true` | 是否启动超时扫描调度器 |
| `SEAT_SCHEDULER_INTERVAL_SECONDS` | `60` | 扫描间隔 |
| `SEAT_ACS_TOKEN` | 空 | 闸机端点令牌；留空则禁用 `/api/acs/*` |
| `SEAT_PUBLIC_BASE_URL` | 空 | 二维码桌贴中的对外地址；反向代理或 ngrok 场景必须设置 |
| `SEAT_ENV_FILE` | 空 | 指定 `.env` 文件路径 |

## 6. 外部服务

| 服务 | 是否必需 | 说明 |
|---|---|---|
| 反向代理 + HTTPS | 生产必需 | 生产环境 Cookie 带 `Secure`，纯 HTTP 会出现“登录成功但立刻退出” |
| ngrok | 可选 | 临时外网演示；免费版首次访问有提示页，域名每次重启变化 |
| 闸机 / ACS | 可选 | 未接入时使用网页签到或桌贴二维码签到 |
| 邮件 / 短信 / 微信推送 | 未接入 | 当前仅站内消息，切页或回到窗口时更新未读角标 |

## 7. 验证命令

在 `智慧自习室预约管理系统/seat_reservation` 目录执行：

```powershell
.\.venv\Scripts\python.exe -m pytest -q          # 510 passed, 1 skipped
node --test tests/*.test.cjs                      # 39 passed
.\.venv\Scripts\python.exe run.py doctor          # 数据库可写、迁移版本、目录权限
```

跳过项为未安装 Playwright 的浏览器端到端用例（`tests/test_e2e.py`）。测试库默认创建在系统临时目录，pytest 退出时自动删除；需要保留现场时设置 `SEAT_TEST_DB_DIR`。

## 8. 生产环境核对

- `SEAT_ENV=production` 且 `SEAT_COOKIE_SECURE=true`；
- 数据库位于本地磁盘，目录仅运行用户可写；
- 已配置反向代理透传 `X-Forwarded-For`，审计日志能记录真实来源 IP；
- 已设置 `SEAT_PUBLIC_BASE_URL`，桌贴二维码指向可访问的域名；
- 已开启 NTP，签到窗口、超时释放与凭证有效期依赖系统时间；
- 已将 `Y0001` 的初始密码改为强密码。
