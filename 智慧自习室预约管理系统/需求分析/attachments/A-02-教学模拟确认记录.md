## TR-01 模拟业务人员讨论：预约与时段的参数设定

| 项 | 内容 |
|---|---|
| 记录编号 | TR-01 |
| 类型 | 教学模拟访谈（成员扮演自习室管理方） |
| 参与者与角色 | `陈景标`（模拟业务人员）、`沈家炜`（记录与提问） |
| 日期 | `2026-10-08` |
| 输入材料 | SRC-01 课程任务说明；SRC-02 教学模拟情景设定（痛点 PB-01~PB-05）；AI 生成的候选参数草案 |
| 议题 1 | 单次预约时长与粒度如何设定？ |
| 讨论要点 | 成员 A 提出"自习通常 1~2 小时，考试周可能连续 3~4 小时"；成员 B 指出若允许过长时段，座位会被"占而不走"；双方接受"30 分钟粒度、单次 0.5~4 小时"，并承认该数值缺乏真实数据支撑 |
| 结论 | 采用候选值：粒度 30 分钟，单次 0.5~4 小时（**候选值，教学模拟确认**）；对应 M-03-1、BR-01 |
| 议题 2 | 每人每日预约数量与总时长上限？ |
| 讨论要点 | 成员 A 建议"每人每天最多 2 个时段、合计不超过 4 小时"，理由是保证公平分配；成员 B 提出"如果取消后是否释放额度"——双方认可"取消/违约/释放不计入当日额度" |
| 结论 | 采用候选值：每人每日 ≤ 2 个时段且 ≤ 4 小时；取消/违约/释放不计入（**候选值，教学模拟确认**）；对应 M-03-2、BR-02 |
| 议题 3 | 可以提前多久预约？ |
| 讨论要点 | 成员 A 提出"未来 7 天"，理由是与课程表/考试安排的可见范围相匹配；成员 B 认为 7 天既能提前规划又不至于被长期占用 |
| 结论 | 采用候选值：未来 7 天内（含当日）已开放时段（**候选值，教学模拟确认**）；对应 M-03-3、BR-03 |
| 议题 4 | 开放时段范围？ |
| 讨论要点 | 参照教学模拟情景（自习室 07:00 开放、23:00 关闭），讨论是否允许跨零点；结论为不跨零点，简化管理 |
| 结论 | 开放时段 07:00—23:00（**教学模拟设定**）；对应 FR-22、BR-03 |
| 未确认事项 | 考试周是否延长开放、是否设置"预约缓冲期"（相邻预约之间预留清座时间）——保留待确认，见 M-08、M-12 |

## TR-02 模拟学生用户讨论：签到、暂离、取消与候补

| 项 | 内容 |
|---|---|
| 记录编号 | TR-02 |
| 类型 | 教学模拟访谈（成员扮演学生用户） |
| 参与者与角色 | `沈家炜`（模拟学生用户）、`陈高阳`（记录与提问） |
| 日期 | `2026-10-08` |
| 输入材料 | SRC-01；SRC-02；候选规则草案（签到窗口、暂离时限、取消规则、候补规则） |
| 议题 1 | 到馆后多久内必须签到？ |
| 讨论要点 | 成员 B 表示"从宿舍走到自习室大约 10 分钟，提前 15 分钟到比较从容"；成员 C 追问"迟到怎么办"，双方接受"开始后 15 分钟内仍可签到，超过即违约" |
| 结论 | 签到窗口 = 开始前 15 分钟 ~ 开始后 15 分钟（**候选值，教学模拟确认**）；对应 M-01-1、BR-04 |
| 议题 2 | 中途外出能否保留座位？保留多久？ |
| 讨论要点 | 成员 B 提出"吃饭或上课需要 30 分钟左右"；成员 C 提出"若更久应释放给他人"；结论为暂离保留 30 分钟，超时自动释放并记违约 |
| 结论 | 暂离保留 30 分钟（**候选值，教学模拟确认**）；对应 M-01-2、BR-05 |
| 议题 3 | 临时有事怎么取消才不算违约？ |
| 讨论要点 | 成员 B 认为"提前 30 分钟取消比较合理，太晚取消别人来不及补位"；成员 C 提出"开始后不允许自助取消，避免用来规避违约" |
| 结论 | 开始前 ≥ 30 分钟取消不记违规；< 30 分钟取消扣 5 分；开始后不可自助取消（**候选值，教学模拟确认**）；对应 M-03-4、BR-10 |
| 议题 4 | 座位满员时怎么办？ |
| 讨论要点 | 成员 B 希望"能排队、有人走了通知我"；成员 C 提出"通知后必须限时确认，否则会占着名额不用" |
| 结论 | 候选：候补按加入时间排序，座位释放后通知队首若干人，5 分钟内确认，超时顺延（**AI 候选，教师确认未开展 → 保留待确认**）；对应 M-09、BR-08 |
| 议题 5 | 需要哪些提醒？ |
| 讨论要点 | 成员 B 提出"开始前提醒、违约告知、候补通知"；成员 C 补充"座位被封禁导致取消要告知且不该罚学生" |
| 结论 | 必须通知的事件清单（**分析推导，团队已复核**）；对应 BR-16 |

## TR-03 模拟教师讨论：违约约束与统计口径

| 项 | 内容 |
|---|---|
| 记录编号 | TR-03 |
| 类型 | 教学模拟访谈（成员扮演教师） |
| 参与者与角色 | `陈高阳`（模拟教师）、`陈景标`（记录与提问） |
| 日期 | `2026-10-08` |
| 输入材料 | SRC-01；候选信用分规则；KPI 草案 |
| 议题 1 | 违约如何约束才合理？ |
| 讨论要点 | 成员 C 认为"扣分要分级：未签到最重，超时未签退较轻"，并强调"要给申诉机会，避免系统故障冤枉学生"；对照候选分值（未签到 −10、暂离超时 −5、超时未签退 −5、虚假上报 −20）逐项讨论后接受 |
| 结论 | 采用候选扣分表（**候选值，教学模拟确认**）；对应 M-02-1、BR-06 |
| 议题 2 | 什么情况下禁止预约？ |
| 讨论要点 | 成员 C 提出"信用分低于 60 分暂停预约"；成员 A 追问"连续不签到怎么办"，成员 C 认为"连续 3 次未签到应短期停止预约，7 天比较合适" |
| 结论 | 信用分 < 60 禁约（**候选值，教学模拟确认**，M-02-2）；连续 3 次未签到限制 7 天（**教师已确认（教学模拟）**，M-02-3、BR-15） |
| 议题 3 | 教师应看到什么？ |
| 讨论要点 | 成员 C 表示只需要"本班使用与违约汇总"，不希望看到学生个人明细（隐私） |
| 结论 | 教师仅查看本班汇总（**分析推导，团队已复核**）；对应 PR-12、FR-62 |
| 议题 4 | 成功指标怎么定？ |
| 讨论要点 | 讨论座位利用率 ≥ 65%、签到率 ≥ 90% 等目标值，成员一致认为**缺少真实基线数据**，只能作为愿望值 |
| 结论 | KPI-01~KPI-03、KPI-05 保留"**待确认**"；对应 M-06、M-07 |

| 结论 | BR-09、ST-11（**分析推导，团队已复核**）；原型测试 T34、页面走查 U5 验证 |

| 结论 | BR-13（**分析推导，团队已复核**）；原型测试 T17、T18、T45、T46 验证 |
| 议题 5 | 管理员能否直接修改学生信用分？ |
| 讨论要点 | 一致同意**禁止**直接改分，只能通过申诉审核按规则恢复，避免权力滥用 |
