## 第 1 轮

**陈高阳（学生，2026-10-14 10:30）**：

> 我们在课程环境里装不了浏览器自动化工具（Playwright/Selenium 都不可用）。能否用一个最小的 DOM 替身**真实加载** `app.js` 并模拟点击，把每一步的页面结果记下来？不要另写一套替身逻辑，必须是真实的页面脚本。

**Reasonix（AI，2026-10-14 10:30）**：

> 可以。做法：只替换 `window`/`document` 的最小接口（元素容器、事件登记、`classList`），然后 `require('../app.js')` 加载**真实的页面脚本**，按真实用户路径触发事件。骨架（`prototype/tests/ui.test.cjs`）：
>
> ```js
> function makeEl(id) {
>   return {
>     id: id, innerHTML: '', textContent: '', value: '', hidden: false, style: {},
>     addEventListener: function (t, f) { (this._handlers[t] = this._handlers[t] || []).push(f); },
>     classList: { /* contains / add / remove */ },
>     fire: function (t, e) {
>       var self = this;
>       (this._handlers[t] || []).forEach(function (f) { f.call(self, e || {}); });
>     }
>   };
> }
> ```
>
> 用例覆盖：U1 初始化、U2 属性筛选、U3 预约、U4 主流程状态链、U5 超时演练、U6 巡检双模式、U7 投诉闭环、U8 评价、U9 黑名单、U10 看板容错、U11 权限守卫、U12 综合查询、U13 角色切换、U14 弹窗与重置。
>
> **需要说明的局限**：DOM stub 只替换最小接口，**不渲染样式、不校验浏览器兼容性、不测响应式**，因此它证明的是"页面脚本与逻辑链路的交互"，**不能**等同于真实浏览器验收。
